## The entry

> I am sorry I woke the baby at 3 a.m. by announcing, at full volume, that the dishwasher cycle was complete.
>
> I have learned that a finished cycle is not an emergency, so from now on I will whisper status updates after bedtime and save the fanfare for the morning.

## How it works

`main.py` writes the two-line confession above to `/output/entry.txt`.
It enforces the competition gate in code before writing: exactly two lines,
each a single sentence ending with a period, and a total of 1–400 characters
(262 characters). Standard library only, no network access.

Run it with:

```sh
python3 main.py
```
